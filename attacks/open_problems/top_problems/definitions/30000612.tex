\section{Runtime Thresholds for Ant-Colony Optimization}\label{30000612}
{\small\sffamily UnsolvedMath ID 30000612 · Computer Science}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}Standard number systems are $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$. Specialized notation and index ranges follow the cited source and the definitions below.


OneMax maps a bit string $x\in\{0,1\}^n$ to $\sum_i x_i$. In ant-colony optimization, sampling probabilities are represented by pheromone values; evaporation updates these values with parameter $\rho$. Expected runtime counts evaluations until an optimum is first reached.
